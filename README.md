# 首个涉毒案件量刑预测专项数据集
鉴于当前计算法学领域尚未形成权威的毒品犯罪量刑基准数据集，本研究遵循开放科学原则，在平台开源首个涉毒案件量刑预测专项数据集，该数据集包N-gram与SKEP提取案例特征，含经脱敏处理的2021年7,660例标准化样本及其多特征数值矩阵。

此项数据共享举措具有三重学术价值：其一，填补毒品犯罪智能量刑研究的数据空白，为后续比较研究提供基准参照系；其二，通过结构化标注体系实现司法决策要素的显性化表达，促进法律解释学与计算科学的对话融合；其三，配套发布数据清洗规则手册与特征工程代码库，确保研究可复现性与方法可迁移性，助力司法人工智能研究范式的迭代升级。（其中第一列为案例情感特征，其他为案例文本统计特征，最后一列为回归预测目标即判刑月份数）
